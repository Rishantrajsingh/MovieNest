# 🎬 MovieNest

MovieNest is a movie discovery web application built with **React.js** and **Tailwind CSS**. It allows users to search for movies, browse popular titles, and view detailed movie information using the **OMDb API**.

## 🚀 Features

* 🔍 Search movies by title
* 🎥 View detailed movie details
* ⭐ Browse top-rated/popular movies
* 📄 Pagination for search results
* ⚡ Fast API requests with caching
* 🎨 Clean and modern user interface

## 🛠️ Tech Stack

* **React.js**
* **Tailwind CSS**
* **React Router DOM**
* **Axios**
* **OMDb API**
